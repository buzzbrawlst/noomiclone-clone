# NoomiClone Clone

A browser-first physics movement laboratory inspired by gymnastics, calisthenics and parkour.

## Current build
- Full 3D stickman-style active ragdoll
- Individual head, torso, upper/lower limbs, hands and feet
- Real cannon-es rigid bodies and joint constraints
- High-bar with physical two-hand proximity grip
- Grab / release / swing forces
- Tuck, extension, twist and roll torque
- Tumbling mode with powered takeoff
- Landing detection
- Speed, angular velocity, flight, power and grip HUD
- Third-person follow camera
- Pause, reset and 0.5x slow motion
- GitHub Pages compatible with no build step

## Controls
W/S — tuck / extend
A/D — twist
Q/E — roll
SPACE — grab/release on the bar; jump in tumbling mode
SHIFT — movement push
R — reset
P — pause

## Stack
Three.js + cannon-es + vanilla JavaScript.
